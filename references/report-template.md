# 报告模板

只保留有证据的段落。若文本不可用，输出停止说明，不填空式生成其余章节。

```markdown
# 简历 AI 介入线索与内容核验报告

## 一句话结论

<例：文本存在明显的统一重写痕迹，但这不能证明经历虚假；有 2 条高影响成果需要通过过程和指标口径核验。>

## 双轴判断

| 维度 | 结论 | 依据 |
|---|---|---|
| AI 介入线索 | 证据不足 / 有限 / 明显 / 集中 | <覆盖哪些片段、涉及几类独立线索> |
| 内容核验风险 | 低 / 中 / 高 | <哪些声明会影响岗位判断> |

## 证据账本

| ID | 原文短引 | 可观察现象 | 合理替代解释 | 业务影响 | 核验动作 |
|---|---|---|---|---|---|
| S1 | “……” | <只描述文本> | <至少一种> | 低/中/高 | <问题或材料> |

## 优先核验问题

1. <针对最高影响声明的情境问题>
2. <责任边界与本人行动>
3. <指标口径与数据来源>
4. <取舍、失败或复现>

## HR 行动建议

- <常规评审 / 结构化电话核验 / 面试中增加案例复现 / 独立资质核验>
- 不要：<不得据此自动淘汰、诚信定性或分析受保护特征>

## 限制声明

本报告识别的是文本线索和需核验的内容，不鉴定作者身份，也不证明候选人使用 AI、夸大经历或存在欺诈。AI 辅助润色、翻译和职业编辑都有相似表现；任何不利决定都应基于岗位相关证据、统一流程和人工判断。
```

## 短文本停止模板

```markdown
## 结论：证据不足

当前材料只有 <字符/要点数>，不足以区分写作习惯、模板编辑、翻译与 AI 辅助。未形成 AI 介入线索等级。

可继续核验：

1. 提供完整的经历/项目要点；
2. 补充岗位说明，以确定哪些声明影响资格判断；
3. 对关键经历使用统一的情境—行动—结果—取舍问题。
```
